# Head-to-head Failure Notes

This file is the placeholder and policy reference for failure-case notes used
by the benchmark taxonomy and reporting code.

## D29

If a benchmark cell cannot be interpreted cleanly under the current taxonomy,
it should not be force-fit into a misleading comparison table.

Preferred response order:

1. mark the cell inapplicable when the baseline taxonomy does not match the
   dataset construct
2. document the rationale in the generated output or methodology notes
3. avoid smoothing over the mismatch with a hand-wavy overall score

The goal is honest comparability, not coverage for its own sake.
